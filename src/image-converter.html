Supported conversions

Every conversion below runs in your browser. The HEIC decoder is downloaded once, the first time you convert a HEIC photo.

Input formats against the output formats they can be converted to
Input JPG PNG WebP
HEIC / HEIF ✓ ✓ ✓
JPEG ✓ ✓ ✓
PNG ✓ ✓ ✓
WebP ✓ ✓ ✓
  • HEIC input covers HEVC-encoded photos, which is what iPhone and recent Android cameras write. AVIF, animated HEIF and HEIC burst files are not supported.
  • Orientation and supported colour profiles are applied before export to sRGB. EXIF, GPS and source colour profiles are not copied. Unsupported HEIC colour spaces, including HDR, are rejected.
  • Transparent pixels are placed on white for JPEG output. PNG and WebP keep transparency.
  • Animated GIF, APNG and animated WebP files are rejected rather than quietly keeping their first frame, as are files holding several images.
  • Limits are 40 MB per file and 50 megapixels decoded. Very large images can also reach your browser's own canvas limit.
  • WebP output needs browser support; the option is disabled where your browser cannot write WebP.
