Choose the method in your statement's password instructions. Details are used locally when you select Unlock PDF.

Manual password

Leave empty to use the default password: password. For a Maybank password chosen during registration, enter it here.

RHB statement details

Enter only the last four characters, keeping the letter case from your ID or registration number.

The password joins those four characters with the date in YYMMDD format. Example: 789A and 29 July 1981 give 789A810729.

TNG eWallet statement details

Use the number registered with TNG eWallet. Spaces, phone separators, +60 country code and the local leading 0 are removed. Example: +6011-23456789 gives 1123456789.

Maybank statement details

The password uses DD, the English three-letter month and YYYY. Example: 1 January 1980 gives 01Jan1980. If you chose a password during registration, select Enter a password.
