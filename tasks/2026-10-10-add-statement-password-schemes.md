# Add statement password methods and direct PDF instructions

## Summary

- Added a password method selector with conditional RHB, TNG eWallet and Maybank fields, while retaining manual entry and its existing blank/whitespace default `password`. Nonblank manual passwords remain verbatim, including surrounding spaces; manual entry also supports a password chosen during registration.
- RHB joins only the last four ID/business registration characters, preserving case, with birth/establishment date `YYMMDD`. TNG normalizes registered Malaysian local/bare/`+60`/`0060` mobile numbers and rejects malformed input. Maybank uses birth date `ddMmmYYYY` with fixed English month abbreviations. Calendar validation does not use timezone-sensitive date parsing.
- Passwords derive locally on explicit unlock and are not displayed, stored or logged. Method/detail changes discard downloads and cancel queued work; reset clears every method field and restores manual entry. Input errors are announced and focus the relevant field.
- Replaced marketing headings and slogans with direct instructions. Added pure-helper tests, independent AES-encrypted fixtures and browser regressions for each method. Push-only lint CI now includes the password-method tests; deployment triggers and dependencies are unchanged. README and AGENTS.md document the formats and verification.
